# NET-01：Mac 打开 fnOS 管理入口

- 执行时间：2026-07-30 10:13 CST（Asia/Shanghai）
- SAG 候选版本：`1.4.0-fnos.1`
- 候选提交：`f15c23a97621aee8258d85e77a69e191d97de126`
- fnOS 环境：x86-64 VMware，计划最低版本 `1.2.0302`
- Windows 可达地址：`192.168.50.178`
- fnOS VM 地址：`192.168.252.10`

## 结论

通过。Mac 对 `http://192.168.50.178:15666/` 的 HTTP 请求返回 `200`，Chrome
能够显示标题为“SAG-fnOS - 飞牛 fnOS”的登录页，证明既有管理端口转发链路可用。

此项只证明管理入口可达，不证明已经登录，也不证明 SAG 应用入口可用。采集时
`192.168.50.178:3080` 仍在 3 秒连接超时内不可达，NET-02、正式 FPK 安装及应用启动
完成前不得把该结果记为 SAG 服务验收通过。
