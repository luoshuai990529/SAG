# SAG fnOS 返回启动页设计

## 目标

在 fnOS 无认证单用户模式中恢复 main 分支已有的“退出到启动页”体验，让用户能够重新填写显示名称，而不删除知识库或其他 `/data` 数据。

## 交互

- 侧栏底部用户菜单显示红色“退出到启动页”。
- 设置页的“本地身份”区显示同名按钮与 main 一致的说明。
- 两个入口均不显示确认框；点击后立即返回 `/login`。
- 若服务端重置失败，页面保持当前身份并显示失败提示。

## 数据与 API

- 新增 `DELETE /api/v1/auth/session`，仅在 `SAG_AUTH_MODE=single_user` 时可用；其他模式返回 404。
- 重置只将唯一用户记录的 `name` 设为空，绝不删除 `users` 记录。
- 空名称代表未完成首次设置：`GET /api/v1/auth/session` 返回 `setup_required=true`，受保护请求返回 401。
- 后续 `POST /api/v1/auth/session` 用新名称原地更新同一用户记录，因此保留用户 ID 以及知识库、图谱、会话和设置的关联。

## 版本与发布

- 包版本升级为 `1.4.0-fnos.5`，以便 fnOS 将其识别为对 `.4` 的升级。
- 该包必须在变更合入 `feat/fnos-docker-app` 后由既有候选发布流程构建，因为 FPK 只接受已发布的不可变 GHCR 镜像摘要。
